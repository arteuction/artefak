# ARTeuCtion — Domain and Code Navigation Map

## System shape

- **Transactional Core:** canonical state for cultural assets, commercial lots, auctions, offers, payments, settlement, fulfillment, donations, impact and governance.
- **ArtMetro:** downstream cultural/geographic layer: venues, exhibitions, QR artifacts/scans and routes. Do not make it a competing source of financial truth.
- **HTTP/API:** versioned endpoints, auth/policies, DTO/resources, OpenAPI annotations generated by Scramble.
- **Async boundary:** Stripe webhook inbox, domain-event outbox, queue jobs, consumer inbox, transfer/reversal lease processing.
- **Frontend:** React SPA using generated API types, TanStack Query for server state and Echo/Reverb for live notifications; database-backed API remains the authority.

## Change trace checklist

For any domain behavior, trace this chain where applicable:

`Route → middleware/auth → controller → request validation → policy → domain/application action → transaction/state change → domain event/outbox → queue/provider → API response/resource → frontend caller → tests → observability/runbook`.

Do not force every feature through every layer; identify which parts actually apply and call out any new boundary introduced by the change.
